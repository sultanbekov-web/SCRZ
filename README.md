# Sweet Crazy — статический сайт каталога

Сайт работает без PHP, базы данных и сборки проекта. Используются обычные HTML, CSS и JavaScript.

## Файлы

- `index.html` — структура сайта.
- `styles.css` — оформление и адаптация под телефон/компьютер.
- `app.js` — каталог, корзина, редактирование товаров и резервное копирование.

## Как открыть

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в браузере.

Для локального просмотра этого достаточно. Для публикации загрузите все три файла на статический хостинг (например, GitHub Pages или Netlify). PHP не требуется.

## Редактирование каталога

1. Нажмите **Управление**.
2. Включите режим редактирования и добавляйте/изменяйте товары.
3. Изменения автоматически сохраняются в `localStorage` браузера.
4. В окне управления используйте **Резервная копия**, чтобы скачать JSON-файл с каталогом и корзиной. Копию можно восстановить через **Восстановить копию**.

## Важно о сохранении

Сайт статический: изменения сохраняются в браузере и на том устройстве/в том браузере, где вы их внесли. Они не синхронизируются автоматически между разными устройствами и посетителями. Для переноса каталога используйте резервную копию. Серверная часть и PHP не нужны.
